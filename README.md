# 合肥老城区步行环境偏好问卷

GitHub Pages静态问卷，用于研究者使用同一台iPad现场采集。

答案逐题写入当前浏览器IndexedDB，不上传GitHub，不使用GitHub Issues保存答卷。其他设备不能查看或汇总这台iPad的记录。每日通过“本设备采集管理”生成JSON备份，保存到文件App，再导入电脑上的本地研究者端。

请使用同一浏览器、普通模式；无痕模式、清理网站数据、更换设备或浏览器会影响本地答卷。导出动作不会删除已有答卷。

完整研究者平台、Python/DCM程序、数据库和密码均不在本仓库中。网站公开不等于答卷公开。

数据阶段保留在study.json及每份记录中；网页发布不自动把预调查改成正式样本。
